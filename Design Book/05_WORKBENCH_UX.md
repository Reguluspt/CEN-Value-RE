# 05 — Workbench UX
**Status: REVIEWED**

Top level: Case Portfolio + Appraisal Workbench.
Workbench: Header | Case Navigation | Main Workspace | Context Drawer | Case Readiness Bar.

Vietnamese/non-IT friendly; preserve Excel muscle memory. Adjustment Grid is the most spreadsheet-like area. TSTĐ uses structured long form. Context Drawer contains provenance/intelligence. Readiness measures workflow completeness and jumps to issues. Keyboard-first where appropriate. Autosave. Validation tolerant while editing, on-blur validation, strict at readiness/export.
